# Arenas UI

Arenas UI is an open-source Tailwind CSS v4 component library
and design system.

## Requirements

- Node.js 26 LTS
- pnpm 12.22.0
- Git

## Getting started

Clone the repository and install dependencies:

```sh
pnpm install --frozen-lockfile
```
